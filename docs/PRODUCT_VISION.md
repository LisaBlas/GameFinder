# Product Vision

## Core Use Case
A gamer already has a specific idea in mind — a genre, setting, or mechanic
combination ("bullet hell", "ancient China", "vikings + strategy"). GameFinder
lets them pick the exact IGDB keywords for that idea, organized into logical
categories, and surfaces games that fit it precisely.

This is the high-value path. Curated keywords can surface games no one would
otherwise find, but that match the user's intention exactly — that precision
is the product's core differentiator, not a secondary feature.

## Secondary Use Case
Users also start from a game they already like and search for similar ones
(the "find similar" flow, seeded from an existing game's genres/themes/
keywords). This is common, but it isn't what makes GameFinder unique — any
recommendation engine can do "more like this."

## What This Means for UX and Product Decisions
- The keyword-selection and discovery-card flow is the primary value prop —
  protect it, don't bury it under other features.
- Judge UX friction against the core use case first: can a user with a
  specific idea get from that idea to a fitting keyword combination quickly
  and confidently?
- Ties to `~/docs/BUSINESS_OBJECTIVES.md`'s affiliate-revenue bet on
  GameFinder — conversion depends on users actually reaching games that match
  their intent, which depends on keyword discovery working well.
